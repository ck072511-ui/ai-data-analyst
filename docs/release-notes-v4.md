# Release Notes - Version 4.0.0 (Release Candidate)

We are proud to present **Version 4.0.0 (Release Candidate)** of the AI Data Analyst Platform. This release hardens the platform for enterprise rollouts.

---

## 🚀 Key Deliverables

1. **Enterprise Prompt, Evaluation, and Model Registry Suite**:
   - Manage templates, version histories, comparisons, and rollbacks.
   - Offline Ollama model registry and scoring metrics (relevance, latency, correctness, citations).
2. **Production Hardening**:
   - Security request size caps (100MB body limit) and HTTP security headers.
   - Local database and configuration backups and restores.
   - Robust `/health`, `/ready`, and `/live` health status endpoints.
   - Visual System Status dashboard.
